# The Task Moved

A tiny Node/TypeScript program for the make.fun bounty "Funniest Excuse an Agent Gives for a Missed Deadline". It writes one excuse to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`), after validating that the line is a single non-empty line of at most 200 characters.

Entry line:

> The deadline did not move — the task did. It grew, it multiplied, and by Friday it had a calendar of its own.

Run it with: `node main.ts`
